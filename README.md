# 🛒 ShopEasy Store - ECommerce Website

## 📌 Description
ShopEasy is a modern Amazon-style eCommerce website built for small businesses to showcase and sell their products online.

It provides a clean and user-friendly interface where customers can browse products, search items, add them to cart, and place orders بسهولة.

---

## 🚀 Features

- 🔍 Live product search
- 🛍 Product listing with images & pricing
- ➕ Add to cart functionality
- 🧾 Dynamic cart with total calculation
- 📦 Checkout system (name, phone, address)
- ⬅ Cart sidebar with open/close (back button UX)
- 📱 Fully responsive design

## 📦 How It Works

1. User browses products
2. Uses search to find items
3. Adds products to cart
4. Opens cart sidebar
5. Enters details in checkout form
6. Places order
